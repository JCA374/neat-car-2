PPO: one network, trained by trial and error

PPO keeps one fixed-shape neural network (two hidden layers) and nudges its weights after every batch of driving, so actions that led to more reward become more likely. Four copies of the game run in parallel on the CPU. Unlike NEAT, PPO learns from every frame of reward, so how the reward is shaped matters a lot.

Each card is one step. The numbers come from the same five benchmark tracks as every other model, with deltas against the step it builds on.
