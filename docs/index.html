NEAT vs PPO: the fastest lap for the least training

Two ways to teach the same car to drive: NEAT evolves small networks, and PPO trains a fixed neural network with reinforcement learning. Both see the same 40 numbers (8 car readings + 32 lidar distances) and output steering, gas and brake. Each one improves in small steps, and every step is timed on the same laptop.

How the comparison works

The benchmark

  1. Five fixed tracks (seeds 3, 11, 21, 34, 55) that no model trains or validates on.
  2. The raw CarRacing car and reward: no extra penalties or bonuses, deterministic actions.
  3. Up to 2000 frames (40 s). A run ends when the lap is complete. Leaving the map, or not finishing in time, is a DNF.
  4. Lap time = frames to complete the lap ÷ 50.

The training clock

  1. Wall-clock time on one laptop with no GPU, from the start of training until the selected model was saved, including validation and evaluation.
  2. NEAT keeps the generation with the best score on 5 held-out validation tracks. PPO keeps its best evaluation checkpoint.
  3. Size counts trainable numbers: NEAT counts its connections plus node biases, and PPO counts every weight in its policy and value networks.

Add a step

Each step is one small file with the settings and the reason for the change. One command trains it, times it, benchmarks it and updates these pages.

cp experiments/neat/n01_lap_time.toml experiments/neat/n02_my_idea.toml   # edit id, parent, title, why, settings
python scripts/run_step.py experiments/neat/n02_my_idea.toml               # train (timed) → benchmark → site data
git add experiments outputs docs && git commit -m "NEAT n02: my idea"
